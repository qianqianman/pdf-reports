# PDF 报告文件目录

请将 PDF 报告文件放入此目录。

文件路径应与 `src/data/reports.json` 中的 `file` 字段一一对应。

例如：
- 将文件 `annual-2024.pdf` 放入本目录
- 对应 `reports.json` 中的 `"file": "/reports/annual-2024.pdf"`
